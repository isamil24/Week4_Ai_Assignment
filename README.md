
# Basic Calculator 🧮

A simple and modern calculator built using HTML, CSS, and JavaScript.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal point support
- Division by zero protection
- Previous calculation display
- Calculation history
- Show and hide history
- Clear calculation history
- Delete last number
- Keyboard support
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the calculator.

## Keyboard Controls

| Key | Function |
|---|---|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| . | Decimal point |
| Enter | Calculate result |
| Backspace | Delete last number |
| Escape | Clear calculator |
